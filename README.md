# Bloom & Belong

Bloom & Belong är ett communityforum där användare kan skapa konton,
gå med i grupper och delta i diskussioner kring olika intressen.

## Teknik

- PHP
- MariaDB
- HTML
- CSS
- Docker
- phpMyAdmin
- Postman

## Starta projektet

Projektet körs med Docker.

Starta projektet med:
docker compose up

Webbplatsen finns på:
http://localhost:8080

phpMyAdmin finns på:
http://localhost:8081

## Funktioner

- Skapa användarkonto
- Logga in och logga ut
- Skapa grupper
- Se grupper man inte är medlem i
- Ansöka om medlemskap i grupper
- Godkänna medlemsansökningar
- Starta diskussioner i grupper
- Svara på diskussioner

## API

Projektet innehåller ett API i `api.php`.
API:t har testats med Postman.
